# Luck Now

Production-grade on-device Android APK for lottery draw sequence analysis.

## Features

- Hidden WebView with shouldInterceptRequest JSON interception (offline-capable)
- Qwen2.5-0.5B/Q4_K_M GGUF via llama.cpp JNI with rigid prompt
- Chaquopy CPython 3.10 + scipy/statsmodels statistical analysis (chi-square, ACF, Ljung-Box)
- Cucumber-Android BDD with 6 features / 9 scenarios
- GitHub Actions CI/CD producing signed arm64-v8a + x86_64 APKs

Product is Luck Now, not Sequntia.
